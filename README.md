# Create Big Cannons: Ballistic Calculator

Калькулятор баллистики для мода Minecraft Create: Big Cannons.

## Возможности
- Расчёт двух траекторий (настильная и навесная)
- Учёт сопротивления воздуха и гравитации Minecraft
- Desktop-версия (Python + customtkinter)
- Web-версия (HTML/JS, работает в браузере без установки)
- Автоматическая сборка через GitHub Actions

## Быстрый старт

### Web-версия
Просто откройте файл \web/index.html\ в любом браузере.

### Desktop-версия (Python)
\\\ash
cd python
pip install -r requirements.txt
python gui.py
\\\
