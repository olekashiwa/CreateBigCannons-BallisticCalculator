# 🎯 Мираж-Гео: Баллистический калькулятор для Create: Big Cannons

**[Открыть веб-приложение](https://olekashiwa.github.io/CreateBigCannons-BallisticCalculator/)** | [English Version](README_EN.md)

Этот инструмент мгновенно рассчитывает точные углы наведения (Yaw и Pitch) для вашей артиллерии в моде *Create: Big Cannons*, учитывая гравитацию, сопротивление воздуха, длину ствола и тип снаряда. Забудьте о стрельбе «на глаз»!

---

## 🎒 Подготовка в игре
Отладочный экран (**F3**) — ваш лучший друг. Перед расчётом запишите:
1. **Координаты крепления (Mount):** Блок, к которому крепится поворотный механизм (X, Y, Z).
2. **Координаты цели (Target):** Блок, в который нужно попасть (X, Y, Z).
3. **Длина ствола (Length):** Общее количество блоков от крепления до самого кончика дула (включительно).
4. **Пороховые заряды (Power):** Количество зарядов в казённике.
5. **Направление (Direction):** Сторона света, куда смотрит орудие в неактивированном состоянии (North, South, East, West).

---

## ⚙️ Как пользоваться
1. Введите координаты пушки и цели.
2. Укажите длину ствола и количество зарядов.
3. Выберите направление и **тип снаряда** (включая снаряды из аддона *CBC: Advanced Technologies*).
4. Нажмите **«Рассчитать»**.

---

## 📊 Расшифровка результатов
Калькулятор предлагает два варианта стрельбы:
*   🚀 **Траектория 1 (Низкая / Прямая):** Меньшее время полёта, сложнее перехватить, требует прямой видимости.
*   🌙 **Траектория 2 (Высокая / Навесная):** Идеальна для стрельбы через стены, холмы или укрепления.

| Параметр | Описание |
|----------|----------|
| **Yaw** | Горизонтальный угол поворота орудия (в градусах). |
| **Pitch** | Вертикальный угол наклона ствола. *(Over 60 / Under -30 означает, что при текущей мощности такой угол невозможен).* |
| **Время полёта** | Длительность полёта в тиках и секундах. |
| **Взрыватель (Fuze)** | **Критически важно для фугасов!** Установите это значение (в тиках) на взрывателе снаряда для подрыва точно над/в цели. |
| **Точность** | Расчётная вероятность попадания. Если < 90%, рекомендуется пристрелка. |

## 💣 Особенности снарядов и аддонов
Калькулятор содержит профили для стандартных и модовых снарядов (разное сопротивление воздуха и скорость):
*   **AP / Solid Shot:** Высокая скорость, низкое сопротивление. Используйте низкую траекторию.
*   **Grapeshot (Картечь):** Быстро теряет скорость и высоту. Эффективна только на малых дистанциях. Отображает расчётный конус поражения.
*   **Smoke (Дымовой):** Долго висит в воздухе. Используйте высокую траекторию для постановки завесы.
*   **CBC: Advanced Technologies:** Снаряды Adv. HE и Custom AP имеют скорректированные физические константы. 
> ⚠️ **Золотое правило:** Для модовых снарядов калькулятор даёт высокоточную базовую оценку. Всегда делайте 1–2 пристрелочных выстрела перед боевым залпом.

## 💡 Примеры расчётов
**Пример 1: Прямой удар.** Пушка на 100, 64, 100, цель на 150, 64, 100 (Восток, 50 блоков). Ствол 5 блоков, 3 заряда. Калькулятор выдаст Yaw: 90°, Pitch: ~15°.

**Пример 2: Навесной огонь.** Цель за стеной выше вас. Калькулятор предложит Траекторию 2 с высоким Pitch и точным временем для взрывателя, чтобы снаряд перелетел препятствие.

## 🚀 Возможности приложения
- 📱 **PWA:** Устанавливается как приложение на телефон/ПК, работает офлайн.
- 🌐 **3D-визуализация:** Интерактивная сцена полёта снаряда (Three.js).
- 📊 **Сравнение:** Наложение траекторий до 4-х разных снарядов на один график.
- 💾 **Сценарии:** Сохранение и загрузка конфигураций стрельбы в JSON.
- 🎓 **Anki Integration:** Мгновенное создание карточек для запоминания баллистики (требуется AnkiConnect).
